# Galería de gráficos de HOFA RPG
Aquí se encuentra la galería de gráficos de HOFA: https://hofarpg.github.io/hofa-graficos/

## ¿Cómo funciona la galería?
La galería funciona creando ramas por cada personaje de cada usuario, para crea una estructura donde cada usuario es listado con sus respectivos personajes debajo y cada personaje tiene una carpeta con sus gráficos.

## ¿Cómo añadir tus gráficos?
1. Crea una nueva rama desde `main` siguiendo la siguiente estructura en su nombre: `nombre-de-usuario\nombre-del-personaje` (ejemplo: *nami\lexi*). No uses espacios ni carácteres especiales.
2. Renombra tus gráficos con el tipo de gráfico que representan (ejemplo: avatar.png). Si tienes múltiples variantes del mismo tipo de gráfico, dales un número (ejemplo: firma1.png y firma2.png).
3. Selecciona tu rama en el repositorio y sube tus gráficos desde *Add file*.
4. Ve a *Actions*, selecciona *Deploy to GitHub Pages* y dale a *Run workflow*.
5. Al terminar el proceso, la página se habrá actualizado (limpia cache, si no ves cambios). Accede al personaje y ahí estarán los gráficos que hayas subido, con su link listo para copiar.

> **NOTA:** Una vez has creado la rama de tu personaje, puedes seguir usándola para añadir o modificar gráficos. Si cambias un archivo por otro con el mismo nombre, se reemplazará ahí dónde lo estás usando. <ins>Vigila no borrar tu rama (o ninguna otra), o perderás todo</ins>.
