# Galería de gráficos de HOFA RPG
Aquí se encuentra la galería de gráficos de HOFA: https://hofarpg.github.io/hofa-graficos/

## ¿Cómo funciona la galería?
La galería funciona usando ramas para cada personaje de cada usuario, lo que genera una estructura donde cada usuario es listado con sus respectivos personajes debajo y cada personaje tiene una carpeta con sus gráficos.

## ¿Cómo añadir tus gráficos?
1. Crea una nueva rama de `main` desde *New branch* y dale un nombre con la siguiente estructura: `nombre-de-usuario\nombre-del-personaje` (ejemplo: *nami\lexi*).
   No uses espacios ni carácteres especiales.
3. Renombra tus gráficos con el tipo de gráfico que representan (ejemplo: avatar.png). Si tienes múltiples variantes del mismo tipo de gráfico, dales un número (ejemplo: firma1.png y firma2.png).
4. Selecciona tu rama en el repositorio y sube tus gráficos desde *Add file*.
5. Espera a que se ejecute el deploy por si solo.
   Si no lo hace, ve a *Actions*, selecciona *Deploy to GitHub Pages* y dale a *Run workflow*.
7. Al terminar el proceso, la página se habrá actualizado (limpia cache, si no ves cambios). Accede al personaje y ahí estarán los gráficos que hayas subido, con su link listo para copiar.

> **NOTA:** Una vez creada la rama de un personaje, puedes seguir usándola para añadir o modificar gráficos. Si cambias un archivo por otro con el mismo nombre, se reemplazará ahí dónde lo estés usando. <ins>Vigila no borrar tu rama (o ninguna otra), o perderás todo</ins>.
